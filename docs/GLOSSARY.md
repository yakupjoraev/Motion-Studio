# GLOSSARY

Terms with exact meanings in this codebase. When a word appears here, it means this and nothing
else — in code, in docs, in commits, in UI copy.

## Domain

**Block** — a registry entry a user can place: `Hero`, `PricingTable`, `Aurora`. A block is a pure
presentational React component of its props plus a `BlockDefinition`. It does not know it is in an
editor. Never called "component" in docs to avoid collision with React components generally.

**BlockDefinition** — the metadata half of a block: schema, defaults, slots, controls,
capabilities, codegen descriptor. Serializable, contains no React. Lives in `blockRegistry`.

**Node** — an *instance* of a block inside a document. Has an id, props, responsive overrides,
motion, effects, children. `Node` is to `BlockDefinition` what an object is to a class.

**Document** — the whole design: `MotionDocument`. Normalized `Record<NodeId, Node>` plus a
`rootId`, theme, and assets. Serialized as a `.motion` file.

**Slot** — a named child position declared by a block. `Section` has a `children` slot; `Navbar`
has `links` and `actions`. A slot declares what it `accepts`.

**Effect** — a decorative layer attached to a node rather than replacing it: aurora, noise,
spotlight, border-beam. An `EffectInstance` has params, a layer (`behind`/`front`), blend mode, and
opacity. A node can carry several, ordered.

**Motion preset** — a named, parameterised animation recipe. Data, not code. `MotionPreset`
declares how to resolve into an engine config, how to reduce for reduced motion, and how to
generate source.

**Motion channel** — *when* an animation applies: `entrance`, `scroll`, `hover`, `press`,
`cursor`, `continuous`, `exit`. A node carries at most one spec per channel.

**Command** — the only way the document mutates. A `{ type, label, payload, apply }` object whose
`apply` is a pure mutation on an Immer draft. Produces patches, which become a history entry.

**Patch** — an Immer JSON-patch describing one change. Forward and inverse patches are the undo
unit; the document is never snapshotted for history.

**Coalescing** — merging consecutive history entries with the same `coalesceKey` within 400 ms, so
a 200-event slider drag is one undo step.

**Transaction** — a group of commands committed as one history entry. Used for paste, align,
wrap-in-container.

**Registry** — the block catalogue. Split in two: `blockRegistry` (metadata, no React) and
`renderRegistry` (`BlockId → component`). The split is what lets codegen run without React.

**IR** — `CodegenIR`, the intermediate representation between a document and generated source. All
naming, hoisting, dedupe, and class generation happens in `buildIR`; printers only serialise.

**Printer** — a function turning IR into files for one target (`printReact`, `printNext`,
`printHtml`, `printJson`). Deliberately dumb.

**Golden file** — a committed expected output for a `(document × target × options)` combination.
Updating one requires reading the diff; it is the review gate on generated-code quality.

## Geometry

**Screen space** — CSS pixels relative to the viewport. Affected by zoom. Branded `ScreenPoint`.

**Canvas space** — artboard coordinates, zoom-independent. Branded `CanvasPoint`.

**Node space** — coordinates relative to a node's own box. Branded `NodePoint`.

**Viewport transform** — `{ zoom, pan }`. Applied as a CSS transform on one element; driven by CSS
custom properties during gestures.

**Artboard** — the page being designed. Its width equals the active breakpoint's frame width.

**Rect cache** — cached bounding rects for every node element, fed by one `ResizeObserver`. Read by
overlays, marquee, and drop resolution so nothing calls `getBoundingClientRect` in a loop.

**Snap candidate** — a coordinate a dragged edge can align to. Kinds: `grid`, `edge`, `center`,
`guide`, `spacing`. Priority in that reverse order on ties.

**Guide** — a visible alignment line. Either generated by a snap or created by the user from a
ruler.

**Isolation** — the "entered" container. While isolated, clicks select descendants of that node
rather than the node itself. Figma's group-entering behaviour.

**Marquee** — rubber-band selection on empty canvas. Intersect by default, contain with `Alt`.

## State

**Slice** — one concern within the single Zustand store: `document`, `selection`, `viewport`,
`history`, `clipboard`, `ui`, `theme`.

**Selector** — a function reading a narrow piece of store state. Every component subscription is a
selector; there are no whole-store subscriptions.

**Versioned selector** — a memoised derivation keyed on the cheap monotonic `version` integer
rather than a deep equality check.

**Version** — a monotonic counter bumped on every committed document mutation. Memoisation keys off
it.

**Transient state** — a high-frequency value during a gesture (pan, zoom, drag delta, in-flight
scrub). Lives in refs and CSS custom properties, never in React state. Commits as one command on
gesture end.

**Dirty** — the document has unsaved changes. Drives autosave and the save indicator.

## Design

**Token** — a named design value. Three layers: **primitive** (raw scale, no meaning), **semantic**
(what it is for), **component** (a specific usage). Components reference semantic tokens only.

**Semantic token** — `surface-1`, `foreground-muted`, `accent-ring`. Meaning, not appearance.

**Theme** — a `ThemeConfig`: palette seed, scales, elevation style, typography, surface treatment.
Resolves to ~120 CSS custom properties.

**Ramp** — a twelve-step lightness ladder for one hue, generated in OKLCH.

**Contrast repair** — the theme engine substituting a nearby ramp step when a generated pairing
fails its contrast requirement. Always reported, never silent.

**Glass** — a composed recipe of `backdrop-filter` + translucent background + hairline border. Not
a single value. Requires something behind it.

**Elevation** — the layered shadow set. Mode-specific: dark mode uses an inner top highlight rather
than a stronger shadow.

**Motion scale** — a theme multiplier on every duration. `0` is the reduced-motion equivalent, so
reduced motion and the scale are one code path.

## Responsive

**Breakpoint** — `base | sm | md | lg | xl | 2xl`, matching Tailwind's widths so exports are a
direct translation.

**Base props** — the unconditional prop values. `node.props`.

**Override** — a per-breakpoint prop value. `node.responsive[bp][key]`. Sparse: only overridden
keys are stored.

**Cascade** — resolution walks `base → … → active`, applying each override in turn, so `lg`
inherits from `md`. Exact-match resolution is a bug.

**Frame** — the artboard width for a breakpoint. `base` renders at 375 px.

## Quality

**Budget** — a numeric limit enforced in CI: bundle size, Lighthouse score, LCP, frame rate,
render count.

**Render count assertion** — an exact test that a gesture caused zero (or N) React renders of a
given subtree. More reliable than timing assertions on CI hardware.

**Cost class** — `cheap | moderate | heavy`, declared per motion preset and per block. Drives the
scheduler's caps and the inspector's warnings.

**Reduced variant** — the reduced-motion form of a preset. Mandatory. A preset without one does not
merge.

**Meta-test** — a test that runs over every registry entry or every preset, asserting the contract.
Makes an incomplete entry impossible to merge.

**Repair** — an import-time fix for a recoverable document invariant violation (orphan node, stale
`parentId`). Always reported in the import dialog.

## Conventions

**Barrel** — a package's `src/index.ts`, its only public surface. Deep imports are banned.

**Seam** — a deliberate interface boundary that keeps two subsystems independent. The registry
interface between `editor` and `blocks` is the important one.

**Escape hatch** — a `css` prop allowing raw CSS on a block, validated and sanitised. Deliberately
narrow.

**Chrome** — the studio's own UI: panels, top bar, status bar, overlays. Distinct from **content**,
which is the user's document. Chrome is quiet; content is allowed to be colourful.
