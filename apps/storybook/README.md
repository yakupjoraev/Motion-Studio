# Workshop

Storybook 8 over `packages/ui` and `packages/blocks`.

```bash
pnpm dev:storybook     # localhost:6006
pnpm build:storybook   # static build into storybook-static/
```

The package is named `workshop` rather than `storybook`, because the npm package it depends on already
has that name and a workspace package sharing it makes `check-deps` see a self-dependency — ADR-047.

`--ci` is on the dev script deliberately: without it, a busy port turns into an interactive prompt that
blocks `turbo dev` with no visible question.

## What is where

| Path | What it holds |
| --- | --- |
| `.storybook/main.ts` | Builder, the stories globs, the docgen settings that produce the prop tables |
| `.storybook/preview.tsx` | Decorator order, the four toolbar globals, `a11y.test = 'error'` |
| `.storybook/theme.ts` | Storybook's own chrome, built from the token ramps |
| `src/decorators/` | One decorator per toolbar global |
| `src/docs/` | `introduction.mdx`, and `tokens.mdx` rendered from `packages/tokens` |
| `src/styles/theme.css` | Generated by `pnpm generate:tokens`. Do not edit |

Stories live beside their components, not here.
