## Goal

`packages/tokens` becomes the single source of truth for every design value, and the generator that
turns it into a Tailwind v4 `@theme` block plus a runtime CSS-variable sheet. After this prompt,
`bg-surface-1` works in `apps/web` and resolves through `--ms-color-surface-1`.

## Constraints

### Colour

All colour is OKLCH string literals. The exact ramps and semantic mappings are the tables in
`docs/DESIGN_SYSTEM.md` — use those values, do not invent your own.

`LIGHTNESS_LADDER`, `CHROMA_CURVE`, and `HUE_SHIFT_CURVE` are exported because the theme engine
(prompt 06) generates user palettes from them. Get the shapes right here.

### The contrast test is the point of this prompt

```ts
const TEXT_PAIRS: ReadonlyArray<[keyof SemanticColors, keyof SemanticColors]> = [
  ['foreground', 'surface-0'],
  ['foreground', 'surface-1'],
  ['foreground', 'surface-2'],
  ['foreground-muted', 'surface-1'],
  ['foreground-onAccent', 'accent'],
  // …every pair the design system actually uses
]

describe.each(['light', 'dark'] as const)('%s mode', (mode) => {
  it.each(TEXT_PAIRS)('%s on %s ≥ 4.5:1', (fg, bg) => {
    expect(contrastRatio(SEMANTIC[mode][fg], SEMANTIC[mode][bg])).toBeGreaterThanOrEqual(4.5)
  })
  it.each(UI_PAIRS)('%s on %s ≥ 3:1', (fg, bg) => { /* … */ })
})
```

If a pair fails, **adjust the token, not the test.** The whole reason tokens exist as data is so
this test can exist.

### Generation

`to-tailwind.ts` emits utilities that point at runtime variables:

```css
@theme {
  --color-surface-1: var(--ms-color-surface-1);
  --radius-lg: var(--ms-radius-lg);
  --font-sans: var(--ms-font-sans);
}
```

`to-css.ts` emits the actual values:

```css
:root { --ms-color-surface-1: oklch(100% 0 0); /* … */ }
:root[data-color-mode='dark'] { --ms-color-surface-1: oklch(19.5% 0.010 265); /* … */ }
```

This indirection is what makes a theme change a variable write with zero re-renders. It is the
single most important structural decision in the styling layer — do not collapse it into direct
values.

- Generated files start with `/* Generated by packages/tokens. Do not edit. */`
- Generation is deterministic: running it twice produces identical bytes
- A test asserts the committed `theme.css` matches fresh generation, so a token change without
  regeneration fails CI

### Noise

The turbulence SVG is a base64 data URL constant in `noise.ts` — one asset, no network request. Keep
it under 1 kB.

## Verify

```bash
pnpm --filter @motion-studio/tokens test    # contrast suite must be fully green
pnpm generate:tokens
git diff --exit-code apps/web/src/styles/theme.css   # must be empty: generation is deterministic
pnpm build
```

Then in `apps/web/app/page.tsx`, temporarily render a swatch grid of every semantic token in both
modes. Look at it. Confirm:
- Surfaces are distinguishable but not harsh
- Text is comfortable, not maximum-contrast black on white
- The dark palette is not just inverted light — it has its own weight
- Focus ring is visible on every surface

Then revert the page.
